口上テンプレート（キャラ別口上の雛形）

このフォルダは ERB の外にあるので、置いたままではゲームに読まれません。
書くときは 100_なまえ をフォルダごと ERB/口上/ に写し、次の3か所を替えてください。

  1. フォルダ名 100_なまえ → <キャラ番号>_<キャラ名>（例 100_花子）
  2. 各ファイルの関数名の 100 → キャラ番号（@口上_一言_100 → @口上_一言_100 のまま／101 なら @口上_一言_101）
  3. 台詞

キャラ番号は CSV/chara の 番号 と同じ。同梱キャラは 1〜60、61〜99 は同梱の追加用、100〜499 が自作キャラの帯です。
主人公（あなた）は番号 0 で、置き場が別です。あなた口上/ の 行為.ERB・妊娠.ERB・破瓜.ERB・絶頂.ERB を ERB/口上/あなた口上/ の直下に写してください（番号はそのまま 0）。
無ければ設定 [4] で選んだ口上タイプの台詞（個室の行為は ERB/口上/あなた口上/汎用/、妊娠は ERB/口上/汎用/）。主人公は喋る側なので、行為の台詞は相手向けとは立場が逆です。

入口は7つ（行為にはほかに任意の盛り上がり版 @口上_盛り上がり_<番号> があります）。要らないファイルは消して構いません。
  一言.ERB   @口上_一言_<番号>(番号)              相手を選んだ画面の一言
  行為.ERB   @口上_行為_<番号>(番号, 行為, 向き)   個室の行為ごと
  妊娠.ERB   @口上_妊娠_<番号>(番号, 局面)         妊娠・出産の局面ごと
  破瓜.ERB   @口上_破瓜_<番号>(番号)               膣に初めて入れられた一手（行為の口上の代わりに出る）
  絶頂.ERB   @口上_絶頂_<番号>(番号, 部位)         部位の快感が線に達した一手・射精した一手（地の文の後に出る）
  着替え.ERB @口上_着替え_<番号>(番号, 場面)       あなたが衣装棚から服を着せたとき（場面 0 普段の服・1 露出の高い服）・断ったとき（2）
  訪問.ERB   @口上_訪問_<番号>(番号, 場面)         あなたの自宅に訪ねてきたとき（場面 0 玄関・1 同居人が部屋に）・帰されたとき（2）

行為の口上は、盛り上がるにつれて台詞を変えられます（任意）。同じ 行為.ERB に @口上_盛り上がり_<番号>(番号, 行為, 向き, 段) を足すと、段が 1 以上のときだけ先に呼ばれます。
  段 1＝昂ぶり（欲情が2段以上）／段 2＝高まり（いずれかの部位の快感が射精の線の 2/3 以上。あと少しで達する）。段 0（平常）では呼ばれず、いつもの @口上_行為_<番号> が出ます。
  絶頂の口上も、同じ個室で続けて達したとき（2 回目以降）は @口上_連続絶頂_<番号>(番号, 部位, 回数) が先に呼ばれます（空なら @口上_絶頂_<番号> に落ちます）。
  強く達したとき（強さ＝その部位の快感＋欲情÷3 が 強絶頂の線 以上。部位 5 は大量射精）は、さらにその前に @口上_強絶頂_<番号>(番号, 部位, 回数) が呼ばれます（空なら 連続絶頂 → 絶頂 に落ちます）。個室の外（自慰・夜這い・舞台）では口上は出ません。方言版は作っていないので、方言の素質が付いていても標準語の強絶頂に落ちます。
  同じ一手で、あなたも相手も達したとき（同時絶頂）は、★の行の後に @口上_同時絶頂_<番号>(番号) が呼ばれます（部位・回数は取りません。空なら何も出ません。相手、あなたの順）。
  あなた用は @口上_同時絶頂_0(番号)。タイプ別は @口上_同時絶頂_元気_女 ／ あなた用 @口上_同時絶頂_元気_主人公_女 のように 連続絶頂・強絶頂 と同じ名前の付け方です。
  方言版も書けます（同時絶頂は同梱で 関西・博多・広島・東北 を用意）：@口上_同時絶頂_元気_女_関西 のように末尾に _関西。方言の段を先に探し、無ければ標準語に落ちます。
  RESULTS が空なら いつもの @口上_行為_<番号> に落ちるので、変えたい行為だけ書けば足ります。値は 盛り上がりの段(番号) でも読めます（@口上_行為 の中で分岐してもよい）。

行為の口上は、確率で「喘ぎ声中心」の口上に替わります（任意。同梱のタイプ別には全 11 タイプ分が入っています）。
  @口上_喘ぎ_<番号>(番号, 行為, 向き, 段)   主人公は <番号>＝0。盛り上がりの段ごとの確率（平常 15％／昂ぶり 35％／高まり 60％。数は仮）で、その行為の口上の代わりに先に呼ばれます。
  喘ぐのは触られる・される側（向き 0＝相手／1＝あなた／2＝双方）と、挿入・キスのとき。会話・見せる・脱衣は喘ぎません。RESULTS が空なら、書いた行為の口上（@口上_行為_<番号>）があればそちら、無ければタイプ別の喘ぎ（言葉つき／喘ぎ声だけ）になります。
  自分で @口上_行為_<番号> を書いてある行為は、@口上_喘ぎ_<番号> を書かない限り汎用の喘ぎに替わりません（書いた台詞が勝手に差し替わらない）。
  タイプ別は ERB/口上/汎用/タイプ_◯◯_喘ぎ.ERB（@口上_喘ぎ_元気_女 など。男・女のみ。ふたなり・性別なしは女。方言版はありません）。群＝喘ぎの群(行為)：0 愛撫／1 奉仕／2 Ｖ系／3 Ａ系／4 キス（-1 は喘ぎ対象外）。
  言葉の無い版は ERB/口上/汎用/喘ぎだけ.ERB（型：賑やか／並／控えめ）。

どれも台詞を RESULTS に返します。空のままなら口上タイプ別（ERB/口上/汎用/）に落ちるので、書きたい所だけ書けばよい。
口上タイプ別の書き方と、分岐に使える値の例は ERB/口上/汎用/ の各ファイルの頭にあります。

方言版を書くこともできます（任意）。素質 方言_関西 のようなものが付いているキャラには、各段で先に「_関西」付きが呼ばれます。
  例：@口上_行為_元気_女_関西（ファイルは ERB/口上/汎用/タイプ_元気_女_関西.ERB）。主人公用は @口上_行為_元気_主人公_女_関西。
  博多弁（素質 方言_博多）も同梱：@口上_行為_元気_女_博多（ERB/口上/汎用/タイプ_元気_女_博多.ERB）。広島弁（素質 方言_広島）も同梱：@口上_行為_元気_女_広島（ERB/口上/汎用/タイプ_元気_女_広島.ERB）。東北弁（素質 方言_東北）も同梱：@口上_行為_元気_女_東北（ERB/口上/汎用/タイプ_元気_女_東北.ERB）。関西・博多・広島・東北とも全 11 タイプ分が入っているので、書き方の見本にできます（広島弁・東北弁は標準語版を規則で変換して作ったので、言い回しは直して構いません）。
  書いた行為だけ方言になり、空なら標準語に落ちます。方言を増やすときは CSV/Talent.csv の 160〜169 に 方言_◯◯ を足し、関数名の末尾に _◯◯ を付けます。
  キャラ別（@口上_行為_<番号>）は元から好きな言葉で書けるので、方言の段はありません。

一人称・二人称（任意）：台詞の中の自分の呼び方・相手の呼び方を、遊ぶ人が変えられるようにできます（主人公を作る [11]・怪しい店の施術）。
  %自称_あたし(番号)% は、キャラに一人称が設定されていればその語、無ければ「あたし」が出ます。相手の呼び方は %対称_あんた(番号)%。
  使える語：自称＝あたし あたくし わたし わたくし 私 おれ 俺 ぼく 僕 うち おら／対称＝あなた あんた お前。
  台詞の行は RESULTS '= @"「…」" の形（@ を付ける）にしてください。@ が無いと % がそのまま画面に出ます。キャラ別口上にも使えますが、キャラ別は元から好きな言葉で書けるので必須ではありません。

遊ぶ人は、キャラごとに口上を「なし」にできます（能力表示の別画面の [2940]。キャラCSVの `フラグ,口上なし,1` で最初から なし にもできます）。「なし」のキャラは上の入口が呼ばれません（台詞だけ止まり、地の文は出ます）。
書き手の側で特別なことをする必要はありません。

見本（見本/ フォルダ）
  同梱キャラ10人（1 あかり／5 とおる／7 しおり／12 せな／13 かえで／18 つばき／20 しゅう／23 なおき／26 ゆうじ／30 りん）の書き下ろし例です。口上タイプ10種を一人ずつ、一言・着替え・訪問・破瓜・絶頂（強絶頂・同時絶頂つき）・妊娠を書いてあります。
  ERB の外にあるのでゲームには読まれません。声の作り方（一人称・語尾・好感度の段での替え方・方言をキャラ別に直接書く）の参考にしてください。
  そのまま使いたいときは、フォルダごと ERB/口上/ に写せば、そのキャラにだけ効きます（関数名の番号が同梱キャラの番号です）。
